# Pipeline Security Evidence Directory

This directory stores verified execution logs, controlled failure demonstrations, and audit evidence generated by the automated DevSecOps security pipeline.

## Evidence Organization

- `demonstrations/`: Controlled failure recordings and blocked build proof.
  - `demo1-secret-leak/`: Gitleaks detection of synthetic secret, blocked PR, and successful remediation.
  - `demo2-vulnerable-dependency/`: OSV-Scanner detection of known vulnerability, blocked build, and pinned upgrade.
  - `demo3-unsigned-artifact/`: Cosign / SLSA provenance rejection of unsigned test image, followed by verified keyless release.
- `scans/`: Representative scanner reports (Semgrep, CodeQL, Trivy, Syft, Checkov, ZAP).
- `metrics/`: Mean time-to-fix calculations and timestamp logs.

All test evidence reflects actual runs with real timestamps. No mock screenshots or synthetic passes are permitted.
